# K=3 的 λ 自适应性:均匀网格对自适应权重序列

由 `Original_py/run_lambda_path_without_256_checkpoints.py` 生成
(模块 docstring 是完整规格)。一次自适应方法的**认证**运行
(epsilon=0.001,自身搜索值 ≤ 2ε/3 即停,30,000 梯度预算保留为
保险丝),测试台为平台实验的问题:K=3,p=6,n=30,hidden=[4],
tanh,种子 7/8,max_inner=25,lambda_max_starts=64——除此之外
均为 `output/plateau/K3_p6_n30_h4_tanh_r6_B30000` 的配置。
结局:ε=0.001,**在 13,155 次梯度处认证成功**(保险丝 30,000 的
44%),共 180 轮,停止时的搜索值 6.57e-04。

- `lambda_path_triangle.png`——K=3 权重单纯形画成三角形。
  蓝色空心圆:基线的权重(均匀网格,r=10,66 个节点)——在看到
  问题之前就由 (K, r) 定死,因此不需要、也没有运行基线。
  橙色实心点:自适应方法的最大—最小搜索在每个外层轮次选出的权重
  (`lambda_history`;星号 = 第 1 轮,叉 = 最后一轮)。相邻轮次
  之间的移动分两种画法:L1 步长小于 0.2 = 橙色粗线段
  (**局部链**——最坏权重滑到了邻近处),L1 步长不小于 0.2 =
  浅灰细线(**全局跳**——预算瞬移到了新的最坏区域)。
- `lambda_step_sizes.png`——每轮相邻权重的 L1 距离(橙色柱 = 链步,
  灰色柱 = 跳步),叠加网格间距 1/r 和链阈值两条参考线、滚动
  中位数、以及每个四分之一段的平均值——分析中引用的"移动收缩
  趋势"直接可读。
- `lambda_path_quarters.png`——序列按时间切成连续的四段,每段一个
  小三角形:覆盖逐步填满、移动随时间变局部。逐格分析见
  `QUARTERS_ANALYSIS_ZH.md`(中文)/ `QUARTERS_ANALYSIS.md`(英文)。
- `summary.json`——运行记录、完整的 `lambda_history`,以及相邻步长
  统计(相邻权重的 L1 距离;单纯形 L1 直径为 2,r=10 网格间距为
  0.1):中位数 0.475,均值 0.615,最大 2.000,小于 0.2 的占 23%。
- `EXPLANATION_ZH.md`——自适应权重为什么不均匀、以及它在什么意义上
  是/不是"一条连续的线"(机制写作,中文)。

注意事项:每一轮的权重是方法**自己的** 64 起点搜索找到的 argmax
(启发式最大化器);without-256 轨道只改变检查点记录的内容,
不影响搜索选出哪些权重。
